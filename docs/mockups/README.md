# Mockups: Startbildschirm (Aufgabe 1)

Statische HTML-Varianten zur Auswahl, einfach im Browser öffnen. Farben, Schrift und Slogan sind Platzhalter.

| Variante | Stimmung | Layout |
|---|---|---|
| `a_nebeltal.html` | Nachtlandschaft, Nebel, Glühwürmchen, Bernstein-Akzent | Titel und Menü links, Szene rechts |
| `b_herbstcodex.html` | Warmes Pergament, Herbstlaub, Rot/Gold | Zentriertes Buch-Panel |
| `c_runenstein.html` | Kühle Schiefer-Optik, rotierende Runenringe, Türkis-Glühen | Zentriert, eckige Buttons |

Enthalten sind pro Variante die Button-Zustände normal, hover/Fokus und disabled (Fortsetzen). Die Auswahl entscheidet über Palette und Theme.
